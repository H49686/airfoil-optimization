
# Airfoil Performance Prediction & Multi-Objective Optimization

## Overview

This project uses Artificial Neural Networks (ANN) to predict airfoil performance
and NSGA-II for multi-objective optimization.

## Objectives

- Predict airfoil performance using ANN
- Evaluate model performance
- Perform multi-objective optimization
- Analyze the Pareto-optimal solutions

## Technologies

- Python
- NumPy
- Pandas
- Scikit-learn
- TensorFlow / Keras
- Matplotlib
- Pymoo

## Project Structure

- `notebooks/01_ANN_baseline.ipynb` – Baseline ANN model
- `notebooks/02_ANN_NSGA2_optimization.ipynb` – ANN + NSGA-II optimization
- `data/` – Dataset used for the project
- `results/` – Generated results and plots

## Methodology

1. Data preprocessing
2. Feature selection
3. ANN model development
4. Model training and evaluation
5. NSGA-II optimization
6. Pareto-front analysis

## Results

The ANN model is used as a surrogate model for airfoil performance,
followed by multi-objective optimization using NSGA-II.
